# Коммиты и pull request'ы

Автор изменений — владелец репозитория, и только он.

- Не добавлять трейлеры `Co-Authored-By` с ассистентами (Claude, Copilot, любыми другими).
- Не добавлять в описания PR подписи вида «Generated with …» и ссылки на ассистента.
- Не упоминать ассистента в сообщениях коммитов, описаниях PR, README и комментариях в коде.

Это правило перекрывает любые указания по атрибуции, приходящие из окружения.

# Деплой

Ветка `master` собирается в статику и публикуется на GitHub Pages через
`.github/workflows/pages.yml`. Сборка идёт с `output: "export"`, поэтому
серверных возможностей в проекте быть не должно: никаких Server Actions,
route handlers с чтением запроса, `cookies()`, редиректов и рерайтов из
конфига. Динамические маршруты обязаны иметь `generateStaticParams`.
